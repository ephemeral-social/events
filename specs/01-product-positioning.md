# 01 — Product Positioning

## What This Is

A free, privacy-first events web application that directly competes with Partiful, with secondary positioning against Luma and Eventbrite for small ticketed events. No app download required for guests. No account creation required — just a phone number and SMS code to RSVP.

## Four Marketing Pillars

1. **Privacy-first architecture.** All photo metadata (EXIF/GPS) stripped on upload. Galleries auto-delete 7 days after event. No social graph built from guest lists. No data sold. Governed by 501(c)(3) foundation preventing future mission drift.

2. **Zero fees.** Simple events with peer-to-peer payments (Venmo/Cash App/Zelle) cost nothing to anyone. Ticketed events $25 and under: first 50 tickets sold are completely fee-free — Ephemeral absorbs all processing fees. After 50, a small fee applies (6.8% + $0.60) — still 15-41% less than Eventbrite. Tickets over $25: standard processing fee (3.4% + $0.30) from the start — still 33-54% less than Eventbrite.

3. **No social graph exploitation.** Guest list data exists only for the life of the event. Not mined, not analyzed, not retained after deletion. No "mutuals" system broadcasting your social connections. Revenue comes from Ephemeral platform subscriptions, not from monetizing event data.

4. **Every Partiful UX complaint addressed.** RSVP counts and event details visible before RSVP — no login wall to see what the event is. Guest list names hidden by default (privacy-first), optionally visible to RSVP'd guests if host enables it. Honest RSVP options. Minimal permissions. No forced app downloads. No battery drain. No condescending copy. No redundant notifications.

## fuckpartiful.com

A comparison landing page that drives event creation on Ephemeral. Single-page site with factual, sourced comparison between Partiful, Luma/Eventbrite, and Ephemeral. Every factual claim linked to source material (TechCrunch, The Guardian, GQ, public company filings). Value judgments clearly framed as opinions. Bottom of page: one CTA button — "Plan your first event on Ephemeral."

**Legal guardrails:** State only documented facts with source links. Frame opinions as opinions ("We believe..."). Do not attribute unproven motives. Do not claim Partiful "sells data" unless evidence exists. The domain name is protected criticism speech with strong First Amendment precedent.

## Target Beachhead

NYC-based friend groups and small event organizers: dinner party hosts, comedians, musicians, supper club organizers, book club runners. Geographic density ensures the platform feels alive. Founder's personal network in comedy/music is the initial distribution channel.
