# 08 — Validation Metrics

## Hypotheses Being Tested

**Hypothesis 1:** People will choose a privacy-focused events tool over Partiful if the UX is comparable or better.

**Hypothesis 2:** The anti-Partiful positioning (Palantir connection, GPS leak, zero fees) drives initial adoption without paid marketing.

**Hypothesis 3:** Event users develop enough affinity to consider a paid social platform (validated via survey and opt-in rates).

## Success Metrics by Phase

**Months 1-2 — Proof of Concept (seeded via founder's network):**

| Metric                            | Target | Signal                                   |
| --------------------------------- | ------ | ---------------------------------------- |
| Events created                    | 50+    | Product is usable                        |
| Total RSVPs                       | 500+   | Guest flow works                         |
| Repeat organizers (2+ events)     | 20+    | Organizers find value                    |
| Visitor → phone verification rate | 30%+   | Phone verification step is not a barrier |
| Zero critical bugs in RSVP flow   | 0      | Core flow is reliable                    |

**Months 3-4 — Organic Growth:**

| Metric                            | Target | Signal                          |
| --------------------------------- | ------ | ------------------------------- |
| Events per month                  | 200+   | Growth beyond founder's network |
| % events by unknown organizers    | 30%+   | Organic adoption                |
| Guest web RSVP completion rate    | 80%+   | Zero-friction RSVP works        |
| fuckpartiful.com → event creation | 10%+   | Marketing funnel converts       |
| Recurring event series active     | 10+    | Stickiest feature is landing    |

**Months 5-6 — Validation:**

| Metric                                                    | Target   | Signal                                 |
| --------------------------------------------------------- | -------- | -------------------------------------- |
| Events per month                                          | 500+     | Product-market fit signal              |
| % events by unknown organizers                            | 60%+     | Self-sustaining growth                 |
| Email/SMS list for Ephemeral launch                       | 5,000+   | Warm audience for full platform        |
| User survey: "Would you pay $7/mo for expanded features?" | 15%+ yes | Conversion potential for full platform |
| Press coverage or viral social moment                     | 1+       | Anti-Partiful positioning resonates    |

## "This Isn't Working" Signals

- After 2 months: fewer than 20 events from people outside founder's immediate friend group → positioning isn't resonating
- People create 1 event but never create a second → product has retention problem
- fuckpartiful.com gets traffic but no conversion to event creation → landing page works but product isn't compelling
- Below 50 events/month by month 4 with majority from personal recruitment → fundamental rethink needed before investing in full platform

## "Push Hard" Signal

100+ events/month by month 4 with 30%+ from strangers → product-market fit confirmed. Accelerate development of full Ephemeral platform. Use traction data in grant applications.
