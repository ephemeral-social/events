# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly. Do not open a public issue.

**Email:** security@ephemeralsocial.com

**GitHub Security Advisories:** You can also report vulnerabilities through [GitHub Security Advisories](https://github.com/ephemeral-social/events/security/advisories/new) on this repository.

Please include as much detail as possible: steps to reproduce, affected components, and potential impact.

## What to Expect

- **Acknowledgment** within 48 hours of your report.
- **Initial assessment** within 1 week, including severity classification and next steps.
- We will keep you informed of progress toward a fix and coordinate disclosure timing with you.

## Scope

**In scope:**

- Authentication or authorization bypasses
- Exposure of user data or private event information
- Cross-site scripting (XSS), cross-site request forgery (CSRF), or injection attacks
- Cryptographic weaknesses (key management, token handling)
- Server-side request forgery (SSRF)
- Privilege escalation

**Out of scope:**

- Social engineering attacks
- Denial of service (DoS/DDoS)
- Issues already reported or publicly known
- Vulnerabilities in third-party services not maintained by this project
- Issues requiring physical access to a user's device

## Coordinated Disclosure

We follow responsible disclosure practices. Please allow us reasonable time to investigate and address the issue before disclosing it publicly. We ask that you do not open public issues, pull requests, or discussions about security vulnerabilities until a fix has been released and we have coordinated disclosure with you.
